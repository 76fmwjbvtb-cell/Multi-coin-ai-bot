Activity log

This version scans up to 12 coins sequentially, which may take time on mobile. This is a standalone local HTML page. Settings, trade history and simulation equity are stored only in this browser's local storage. It does not contain a server or secure API credential vault. Public market-data requests require internet access. The bot tries two Binance endpoints and Kraken; some browser previews, networks, and countries block all cross-site requests. Open the downloaded HTML in Chrome directly, not an in-chat preview. If fetching fails, bot holds and makes no new trade.
